
# Korp backend utilities of the Language Bank of Finland (Kielipankki)

This independent branch of the [Kielipankki-korp-backend
repository](https://github.com/CSCfi/Kielipankki-korp-backend/)
contains utility scripts for the Korp backend of the Language Bank of
Finland (Kielipankki):

- [`authing/`](authing/): Korp authorization database management tool
  [`auth`](authing/auth)
- [`logutils/`](logutils/): Python scripts for processing Korp backend
  logs
